Política de Privacidade — AutoShorts

Última atualização: 20 de novembro de 2026

AutoShorts é uma ferramenta pessoal, usada apenas pelo dono dos canais do YouTube que ela gerencia. Não há outros usuários.

Dados acessados

Com a autorização do dono do canal, via Google OAuth, o AutoShorts usa os serviços de API do YouTube para:

  • enviar vídeos produzidos pela própria ferramenta (permissão youtube.upload);
  • ler informações básicas do próprio canal, como nome e status dos vídeos enviados (youtube.readonly);
  • ler métricas do próprio canal no YouTube Analytics para melhorar os próximos vídeos (yt-analytics.readonly).

Armazenamento

As credenciais de acesso e as métricas ficam somente no computador do dono, em arquivos locais. Nada é enviado a servidores do AutoShorts (não existem) nem vendido, compartilhado ou usado para publicidade.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. O AutoShorts usa os serviços de API do YouTube; ao usá-lo, valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os arquivos locais podem ser apagados pelo dono.
